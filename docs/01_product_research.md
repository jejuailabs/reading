# PRD 01 제품 전략과 조사 근거

[전체 설계로 돌아가기](../main.md)

작성일: 2026-11-16 · 상태: 설계·로컬 프로토타입 착수 · 요구사항 접두사: PROD

현재 구현 범위는 로컬 데이터 어댑터와 창작 데모를 통한 화면·활동 흐름 검증이다. 실제 Firebase Auth·Firestore·Cloud Storage에는 연결하지 않으며, 서비스 개설·외부 AI 호출·배포를 수행하지 않는다. 향후 Firebase 기반 인증·권한·저장 구조는 [PRD 08](08_platform_architecture.md)을 따른다. 로컬 시연 결과를 교육 효과, 실제 학급 업무량 감소, 운영 권한 검증의 증거로 사용하지 않는다.

## 1. 문제와 제품의 역할

교사의 목표는 학생에게 온전한 독서 경험을 제공하는 것이다. 제품은 도서 선정, 서로 다른 읽기 수준 지원, 질문 지도, 표현 활동, 인쇄·배포·기록을 이어주는 역할을 맡는다. 교사가 각 서비스와 문서를 다시 조립해야 한다면 기능 수가 많아도 업무는 줄지 않는다.

학생의 목표는 읽고 듣는 데서 출발해 자기 궁금함을 질문으로 표현하고, 본문과 사람을 통해 알아보며, 자신의 이야기와 해석을 독자에게 전달하는 것이다. 완성품 생성 속도와 학습 과정의 질은 별도로 평가한다.

## 2. 조사 범위와 근거의 한계

- 국내 초등 전 학년, 한국어 독서 수업을 중심으로 조사했다. 해외 도구·연구는 설계 참고이며 한국어 수업 효과로 그대로 일반화하지 않는다.
- 학술자료는 공개 원문 또는 초록에서 확인한 범위만 사용했다. 이번 프로젝트에서 교사·학생을 직접 인터뷰하거나 서비스 로그인 내부를 실사용하지 않았다.
- 서비스 기능·가격의 기준일은 2026-11-16이다. 업체의 기능 설명과 독립적인 교육 효과 검증을 구분한다.
- 이후 표의 제품 대응·수용기준은 이 프로젝트의 설계 제안이다. 조사에서 검증된 절약 시간이나 최적 수업 분량이 아니다.

## 7. 차별화 가설

**같은 책의 읽기·학생 질문·해석·낭독·저작을 이어주고, 교사가 조립·수정·기록하는 시간을 줄인다.** 이 결합이 경쟁사의 모든 상품에 없다고 검증한 것은 아니다. 실제 도입 비교에서 다음을 입증해야 한다.

- 인쇄·웹·오디오·질문·대본의 판본과 위치가 일치한다.
- 교사가 학생 질문 전부에 답하거나 채점하지 않아도 수업이 진행된다.
- 아이의 질문이 토론 주제·역할 해석·새 이야기의 갈등으로 실제 채택된다.
- 수정한 장면의 그림·음성·질문만 갱신해 재작업과 과금을 줄인다.
- 학생의 원문·선택·수정은 보존되고 AI 개입은 식별된다.
- 지역 사실과 창작 설정을 구분하며, 승인된 책을 종이·웹으로 재사용할 수 있다.
- AI와 외부 연동이 꺼져 있어도 읽기·질문·수작업 저작은 지속된다.

고전은 판권·접근성 전략의 일부다. 현대 아동의 경험, 정보글·과학·사회 주제를 보완하기 위해 교사 자체 저작과 학교 보유 도서의 수업 연결을 지원한다. 보호 중인 현대 도서 전문을 무단 업로드하는 방식으로 확장하지 않는다.

## 8. 파일럿과 성공 지표

초기 제안은 학년별 2학급, 총 12학급의 6~8주 실행 가능성 검증이다. 모집·실행·관련 비용은 별도 계획과 승인 대상이며 이번 문서 작성에 포함되지 않는다.

| 측정 | 방법 | 오해하지 않을 것 |
|---|---|---|
| 교사 총시간 | 선정·편집·검수·인쇄·배포·기기·평가·정리를 동일 범위로 기록 | 생성 버튼 대기시간만으로 업무 경감을 주장하지 않음 |
| 질문 자립성 | 처음/끝에 새 글에서 AI 없이 질문·탐색 수행 | 질문 개수·길이를 점수로 환산하지 않음 |
| 독서 참여·이해 | 읽은 장면 설명, 근거 연결, 선택한 방식과 지원 기록 | 화면 체류·오디오 재생을 이해로 해석하지 않음 |
| 창작 전이 | AI 없이 새 장면 구성, 수정 이유 설명 | 보기 좋은 완성책만 평가하지 않음 |
| 협업 | 구성원별 선택·피드백·수정 관찰 | 타자 횟수로 기여·성격을 판정하지 않음 |
| 재사용 의향 | 지원자가 대신 작업하지 않은 두 번째 단원 자발적 사용 | 첫 체험 만족도만 사용하지 않음 |
| 운영 | 로그인·출력 실패, 데이터 접근 거부, 작업 재시도·비용 | 장애를 지원팀의 수작업으로 숨기지 않음 |

파일럿 통과 목표의 예는 재사용 시 준비·운영 총시간 중앙값 30% 감소다. **이는 검증된 효과가 아닌 초기 목표**이며, 학년군별 실제 측정값과 학생 참여 저하 여부를 함께 판단한다. 첫 사용 학습시간과 개발자·연구자의 대행시간도 합산한다.

## 9. 수용 기준

- PROD-AC01: P0 수업은 학생 기기 없이 교사 화면과 인쇄본으로 운영할 수 있다.
- PROD-AC02: 한 단원에서 학생 질문이 실제 읽기·토론·낭독·창작 중 하나에 반영된 사례를 확인할 수 있다.
- PROD-AC03: 평가·녹음·독후감·공개 출판 중 어느 것도 전원 필수 기본값이 아니다.
- PROD-AC04: 서비스 소개의 연구 수치마다 원자료와 표본·시점이 연결된다.
- PROD-AC05: 제품 효과·시장 규모·절감 비용은 실제 검증 전 확정 수치로 홍보하지 않는다.
- PROD-AC06: 무료·유료 경쟁 제품을 비교할 때 본문 권리, 출력, 학생 협업, 교사 운영 범위를 각각 구분한다.

## 10. 사업·도입 가설

구매자는 학교·교육기관, 사용자는 교사·학생일 가능성이 높다. 정액 수업 운영 기능과 승인된 창작 사용량을 구분해 예산 예측 가능성을 높이는 모델을 검토한다. 초기에는 무제한 AI 사용 약속, 자동 유료 전환, 학생별 과도한 과금 유도, 생성량 경쟁을 채택하지 않는다.

도입 검증에는 교사 외에 사서교사·정보 담당자·학교 관리자 관점을 포함한다. 보유 도서·책꾸러미·교육청 서비스로 이미 해결되는 비용을 중복 청구하지 않도록 실제 업무 절감과 콘텐츠 편집 품질을 확인한다.
