# AI 낭독 제작 방식과 추가 비용 승인

확인일: 2026-11-16 · 상태: 승인된 TTS 10회 실행 및 한국어 MP3 10편 생성 완료. 전체 MP3 형식·길이·디코딩 검사와 아래 브라우저 동작 확인 완료. 전편 발음 청취 감수는 미완료

이번 샘플은 **고전 10편의 제목과 한국어 본문을 읽는 정적 MP3 10개**다. 승인 후 OpenAI `tts-1-hd`, 기본 음성 `nova`, 속도 `0.95`, `/v1/audio/speech`로 생성했다. 입력은 고정 원고 그대로이며, 실제 낭독의 원고 충실도와 전편 청취 검수는 별도다. 이 모델은 종료가 예고되어 있으므로 운영 서비스의 장기 기본값으로 채택한 것은 아니다.

사용자는 **2026-11-16 추가 음성 작업 최대 10회·US$1을 명시적으로 승인했다.** 이번 고전 10편의 한국어 전체 책 낭독을 `tts-1-hd`로 제작하는 범위이며, 기존 GPT-6 Luna 텍스트 작업 최대 10회·US$1 승인과 별개다. 두 작업을 합친 예산은 **최대 20회·US$2**이고, 각 작업의 호출·금액 한도를 서로 전용하지 않는다. 승인은 생성 완료나 실제 청구액 확정을 뜻하지 않는다.

| 승인 기록일 | 승인된 작업 | 호출 한도 | 금액 한도 |
|---|---|---:|---:|
| 2026-11-16 | GPT-6 Luna 질문 코칭·동화 구성안 텍스트 | 10회 | US$1 |
| 2026-11-16 | 고전 10편 한국어 전체 책 TTS, `tts-1-hd`·`nova`·MP3·속도 0.95 | 10회 | US$1 |
| **별도 한도 합계** | **이번 개발·샘플 제작 범위** | **20회** | **US$2** |

## 1. 실제 분량과 계산 기준

원고는 `src/lib/classic-catalog.ts`, 기존 Windows 로컬 음성의 길이는 `src/lib/classic-audio.json`에서 읽었다. API·운영 DB·키 파일은 열지 않았다.

| 책 | 장면 | 원래 장면 본문 합계(자) | 최종 요청 입력(자) | 기존 한국어 음성(초) |
|---|---:|---:|---:|---:|
| 흥부와 놀부 | 6 | 1,254 | 1,272 | 217.754041 |
| 해와 달이 된 오누이 | 6 | 1,260 | 1,283 | 209.390042 |
| 혹부리 영감 | 6 | 1,329 | 1,347 | 221.157376 |
| 토끼와 자라 | 6 | 1,314 | 1,332 | 221.597917 |
| 의좋은 형제 | 6 | 1,328 | 1,346 | 233.123208 |
| 토끼와 거북이 | 4 | 734 | 749 | 128.153083 |
| 사자와 생쥐 | 4 | 720 | 734 | 124.811249 |
| 여우와 포도 | 4 | 747 | 761 | 127.781624 |
| 북풍과 태양 | 4 | 737 | 751 | 127.245042 |
| 시골쥐와 도시쥐 | 4 | 766 | 784 | 131.446833 |
| **합계** | **50** | **10,189** | **10,359** | **1,742.460415** |

정확한 입력 계약은 다음과 같다.

```ts
book.title + "\n\n" + book.pages.map(page => page.text).join("\n\n")
```

장면 사이 줄바꿈을 더하면 10,269자, 제목과 제목 뒤 줄바꿈까지 더하면 **10,359자**다. 기존 본문 안의 공백·줄바꿈도 포함하며, 임의로 공백을 제거하거나 정규화하지 않는다. Unicode 코드 포인트 기준으로 계산했고 현재 원고는 JavaScript 문자열 길이와도 일치함을 로컬 검사했다. 교사 질문·출처·낭독 지시문은 음성 입력에 넣지 않는다.

기존 녹음은 총 **29분 2.46초**다. 새 음성은 제목도 읽고 발음·쉼·속도가 달라지므로 같은 길이를 보장하지 않는다. 선택한 `tts-1-hd`의 비용은 출력 분 수가 아닌 입력 문자 수로 계산한다.

## 2. 공식 확인한 모델과 제한

| 방식 | 공식 요금·제약 | 이번 작업의 판단 |
|---|---|---|
| **`tts-1-hd`** | 입력 **100만 문자당 US$30**. 음성 전용 Speech endpoint. [공식 모델·가격](https://developers.openai.com/api/docs/models/tts-1-hd) | 이번 정적 낭독 제작 모델. 문자 기반 견적이 명확하고 음성 품질을 우선하는 전용 모델이다. 전편 발음·본문 충실도의 청취 검수 완료를 뜻하지 않음 |
| `tts-1` | 입력 **100만 문자당 US$15**. [공식 모델·가격](https://developers.openai.com/api/docs/models/tts-1) | 비교 대상. 이번에는 HD로 고정하며 자동 대체하지 않음 |
| `gpt-4o-mini-tts-2025-12-15` | 입력 텍스트 **US$0.60/M 토큰**, 출력 음성 **US$12/M 토큰**, 최대 입력 **2,000토큰**. [공식 모델·가격](https://developers.openai.com/api/docs/models/gpt-4o-mini-tts) | 말투 지시가 가능하지만 토큰 검증과 출력량에 따른 견적이 추가로 필요. 이번 문자 기반 계약에는 사용하지 않음 |
| `gpt-realtime-2.1-mini` | 텍스트 입력 **US$0.60/M**, 텍스트 출력 **US$2.40/M**, 음성 출력 **US$20/M 토큰**. 128k 문맥, 최대 출력 32k토큰. [모델](https://developers.openai.com/api/docs/models/gpt-realtime-2.1-mini), [현재 요금](https://developers.openai.com/api/docs/pricing) | 운영 이행 후보. `/audio/speech`에 모델명만 바꾸는 방식이 아님. 대화형 모델이므로 원고의 누락·의역·추가 발화 검증이 필요 |

공식 Speech 가이드는 위 세 Speech 모델의 **2027-01-06 종료 예정**과 Realtime API로의 이전을 안내한다. 이번 어댑터는 종료 전 샘플 파일 제작용이며, 이후 새로운 생성·수정 제작은 대체 어댑터를 검토해야 한다. 이미 생성한 정적 파일의 재생은 생성 API 호출과 분리한다. [공식 종료·이전 안내](https://developers.openai.com/api/docs/guides/text-to-speech)

2026-11-16 공식 모델 목록과 Speech API 스키마에서 `gpt-6-tts`라는 모델은 확인하지 못했다. 추측한 모델명이나 Responses API의 텍스트 모델을 Speech 요청에 넣지 않는다. [공식 모델 목록](https://developers.openai.com/api/docs/models/all), [Speech API](https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create)

- Speech API의 `input` 최대 길이는 **4,096자**다. 이번 최종 입력은 책당 최대 **1,347자**이므로 `tts-1-hd`는 책마다 한 번, 총 10번으로 요청을 준비할 수 있다. 문자 제한을 UTF-8 바이트 제한으로 오해하지 않는다. `gpt-4o-mini-tts`는 2,000토큰 제한도 별도로 확인해야 한다. [Speech API](https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create)
- `tts-1-hd`는 `nova`를 지원하며 한국어도 지원한다. 공식 가이드는 기본 음성이 영어에 최적화되어 있다고 설명하므로 초등 한국어의 자연스러움을 검증 완료라고 표시하지 않는다. 아동·교사의 목소리 복제와 커스텀 음성 제작은 범위에 포함하지 않는다. [음성·언어 가이드](https://developers.openai.com/api/docs/guides/text-to-speech)
- Speech 출력은 MP3, Opus, AAC, FLAC, WAV, PCM을 지원한다. 이번에는 MP3와 `speed: 0.95`로 고정한다. `instructions`는 `tts-1-hd`에서 작동하지 않으므로 보내지 않는다. 본문에 별도의 낭독 지시문을 끼워 넣지도 않는다. [Speech API](https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create)

## 3. 예상 비용과 정확한 승인 범위

아래는 세금·환율·카드 수수료를 제외한 USD API 기본 사용료다. 계정의 잔액·무료 크레딧·자동 충전 설정은 조회하지 않았다. 무료 실행을 가정하지 않으며 새 결제수단·자동 충전·정기 구독·호스팅·스토리지 유료 기능을 활성화하지 않는다.

| 범위 | 계산 | 기본 예상 비용 | 호출 수 |
|---|---|---:|---:|
| **한국어 10편 전체, 선택한 HD** | 10,359자 × US$30 / 1,000,000 | **US$0.31077** | **10회** |
| 비교: 같은 최종 입력 `tts-1` | 10,359자 × US$15 / 1,000,000 | US$0.155385 | 10회 |
| 별도 두 장면 시험: 흥부 1쪽 + 토끼와 거북이 1쪽, 제목 없이 장면 본문만 | (206자 + 177자) × US$30 / 1,000,000 | **US$0.01149** | **2회** |
| 위 두 장면 시험 후 전체 10편을 다시 제작 | 10,742자 × US$30 / 1,000,000 | US$0.32226 | **12회** |

**승인된 TTS 범위는 전체 10편 최대 10회·US$1이다. 별도 두 장면 시험을 10회에 더해서 실행하지 않는다.** 먼저 흥부와 놀부·토끼와 거북이 두 책을 통째로 생성하면 합계 2,021자, 예상 US$0.06063이다. 이 두 파일을 검수하여 재사용하고 나머지 8편을 생성하면 10회 범위를 유지할 수 있다. 별도 두 장면 시험을 선택하려면 12회 범위를 명시적으로 승인해야 한다.

실패 후 재시도와 원고 변경에 따른 재생성도 호출·비용에 포함한다. US$1은 무제한 재시도 허용액이 아니다. **추가 10회와 US$1 중 먼저 도달하는 조건**을 따르며, 초과 위험이 있으면 중단한다. 자동 유료 대체·추가 저장소·음성 변조·역할극·영어 재생성은 이번 범위 밖이다. 성공한 파일을 재생할 때 생성 API를 다시 호출하지 않는다.

운영 후보 Realtime의 참고 계산은 현재 로컬 음성 1,742.460415초와 공식 출력 음성 환산 20토큰/초를 적용하면 **음성 출력만 약 US$0.696984**다. 텍스트 입력·출력·재생성은 별도다. 두 장면 66.161292초는 음성 출력만 약 US$0.026465다. 이 숫자는 HD 제작 견적이 아니며 새 음성의 길이나 전체 상한을 보장하지 않는다. [공식 사용량·과금 설명](https://developers.openai.com/api/docs/guides/voice-latency-cost?voice-api=realtime)

`gpt-4o-mini-tts`의 토큰 단가는 확인했지만 이번 조사에서 최신 공식 페이지의 분당 환산치를 확인하지 못했다. 따라서 인터넷에서 보이는 US$0.015/분을 현재 확정 단가로 사용하지 않는다. 이번 승인 계약은 문자 기반 `tts-1-hd`에 한정한다.

## 4. 순수 요청 생성 함수와 실행 조건

[narration-request.ts](../src/lib/server/narration-request.ts)의 `buildNarrationRequest(bookId)`는 알려진 고전 ID 문자열만 받는다. 클라이언트가 본문·언어·모델·목소리·URL을 보내거나 바꿀 수 없다. 제목과 한국어 본문을 서버 카탈로그에서 선택하고, 4,096자 제한·빈 원고·알려진 작품 ID를 검증한다.

반환값은 `{ metadata, body }`다. `body`에는 `tts-1-hd`, 원고, `nova`, `mp3`, `speed: 0.95`만 담는다. 메타데이터에는 판본·문자 수·비용·정확한 입력 SHA-256(`sourceHash`)과 생성 설정까지 포함한 `cacheKey`를 담는다. `sourceHash`에는 제목과 줄바꿈도 포함된다. 이 함수에는 키·환경변수 읽기, 네트워크 연결, 파일 저장, API 실행 기능이 없다.

생성 실행기는 서버에서 승인 ID·모델·작품 집합·언어·금액·호출 수·기간을 확인해야 한다. 브라우저의 승인 플래그는 근거가 아니다. 승인된 원고 해시와 현재 입력을 대조하고, 완성·검수된 같은 캐시가 있으면 재생성하지 않는다. 실패·빈 파일·중간 끊김은 성공 캐시에 넣지 않는다. 모델 지원 종료나 접근 거부 시 다른 모델로 자동 우회하지 않는다.

로컬 검사에서 10편의 입력이 정확한 제목·본문 연결과 일치하는지, 가격 계산·모델·음성·속도가 고정되어 있는지, 같은 원고의 해시가 같은지 확인했다. 잘못된 ID·경로 문자열·임의 본문 객체·창작 샘플 ID는 거부했다. 검사는 네트워크 없이 통과했으며 실제 생성 품질 검증은 남아 있다.

## 5. 리더 연결과 품질 검수

기존 로컬 파일은 한국어 50개·영어 50개의 **장면별 음성**이고, 이번 후보는 **한국어 전체 책 파일 10개**다. 앱에서는 ‘책 전체 AI 낭독’과 기존 장면별 기기 음성을 분리하여 선택한다. 전체 책 파일을 특정 페이지의 음성처럼 연결하지 않는다.

페이지별 이동·강조가 필요하면 검증한 시간표를 따로 준비한다. 기존 Windows TTS의 길이를 새 음성의 페이지 경계로 복사하면 안 된다. 강제 정렬·전사·장면별 재생성에 유료 API를 추가하려면 별도 비용·호출 범위 승인이 필요하다. 이번에 승인된 10회 범위에는 포함되지 않는다.

생성 뒤에는 원고의 누락·추가·변경, 한국어 발음, 문단 쉼, 음량, 클리핑, 마지막 문장 완결을 검수한다. 듣기 기능 가까이 AI 생성 음성임을 알린다. 공식 가이드도 AI 음성 고지를 요구한다. [공식 TTS 가이드](https://developers.openai.com/api/docs/guides/text-to-speech)

## 6. 종료 이후 운영 이행

2027-01-06 이후 새 제작이 필요하면 가격·모델 가용성을 다시 확인하고 어댑터를 교체한다. 현재 공식 권장 대체 `gpt-realtime-2.1-mini`는 별도 Realtime 흐름이며 PCM 24kHz 등의 출력을 모아 MP3로 변환하고 사용량을 기록하는 과정이 필요하다. Speech API에 모델명만 교체하는 변경으로 끝나지 않는다. [Realtime 이벤트](https://developers.openai.com/api/reference/resources/realtime/client-events), [음성 수신 흐름](https://developers.openai.com/api/docs/guides/realtime-conversations)

Realtime을 쓰더라도 이 낭독 기능에는 학생 마이크나 대화 기록이 필요하지 않다. 고정 본문의 누락·의역·추가 발화 검수를 통과한 뒤 사용한다. 현재 순수 빌더에는 Realtime 연결이나 자동 대체 기능을 넣지 않았다.

## 7. 승인 후 실행 및 확인 기록

2026-11-16 생성 담당 실행 결과는 **정확히 10회 호출, 입력 10,359자, 자동 재시도 0회**다. 문자 단가로 계산한 추정 API 사용료는 **US$0.31077**이며, 제공자 청구 실액은 조회하지 않았다. 승인된 10회 호출을 모두 사용했으므로 US$1 예산에 잔여액이 있더라도 추가 생성·재생성은 별도 승인 없이 실행하지 않는다.

- 생성 파일: `public/audio/classics-ai/<book-id>/ko.mp3` 10개
- 공개 매니페스트: [classic-ai-audio.json](../src/lib/classic-ai-audio.json). 모델·목소리·속도·생성 시각·판본·문자 수·원고 해시·파일 해시를 기록
- 로컬 읽기 전용 검증: 10개 파일 존재, 문자 합계 10,359자, 현재 제목 포함 원고의 SHA-256과 매니페스트의 `sha256`이 전부 일치. 실제 MP3의 SHA-256도 `audioSha256`과 전부 일치
- 생성 담당 최종 검사: 10편 모두 `ffprobe`의 MP3 형식·길이 확인 및 `ffmpeg` 전체 디코딩 검사 통과. 마지막 캐시 확인 CLI는 `requests: 0`, `keysRead: false`로 추가 생성 호출·키 읽기 없이 종료
- 매니페스트 기준 생성 음성 합계: **1,465.464초, 약 24분 25.46초**. 파일 합계 **23,447,424바이트**. 생성 속도 0.95와 리더의 재생 배속은 별개
- 브라우저에서 확인된 범위: 흥부와 놀부 전체 AI 음성 `duration: 180.624`, `currentTime: 8.83` 재생 진행, 1.25배속 재생 성공. 페이지 이동 중 전체 책 재생 유지, 영어 및 장면 음성 전환 동작 확인, 장면 음성으로 전환할 때 전체 책 재생 정지 확인. 모바일 가로 넘침 없음. [확인 화면](../artifacts/classics-ai-reader.jpg)

전체 10편의 기술적 파일·디코딩 검사는 완료됐으며 브라우저 확인 범위는 위 항목과 같다. 전편의 발음·누락·추가 발화·본문 충실도에 대한 청취 감수는 아직 수행하지 않았다. 기술적 재생 성공을 청취 감수 완료로 간주하지 않는다. 이 문서 갱신은 최종 검사 보고만 반영했으며 추가 API 호출·키 열람·과금 설정 변경은 하지 않았다.
