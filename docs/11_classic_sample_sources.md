# 샘플 고전 10편의 출처와 재서술 기준

작성·출처 확인일: 2026-11-16 · 범위: 전래동화 5편, 이솝우화 5편의 로컬 샘플 제작 근거

이 문서는 **전승된 옛 줄거리를 참고하여 한국어로 새로 쓰는 샘플**의 출처 기록이다. 라이선스 확인을 마친 한국어 저작물 전문을 가져오는 작업이 아니다. 현대 동화책·교과서·번역서·백과사전의 문장, 대사, 장면 구성, 삽화, 낭독 음원을 복제하지 않는다. 작품의 기원이 오래되었다는 사실과 특정 판본·파일의 이용권 확보는 별도로 판단한다.

아래 URL은 실제 공개 페이지를 열어 항목 또는 수록 작품의 존재를 확인했다. `출처 확인 완료`는 `배포 권리 검수 완료`를 의미하지 않는다. 이 문서만으로 [PRD 03](03_library_reader_rights.md)의 판본 권리 상태를 `cleared`로 바꾸지 않는다.

## 2. 출처 자체의 이용조건

### 한국민족문화대백과사전

[공식 콘텐츠 이용 안내](https://encykorea.aks.ac.kr/Guide/ContentUse)는 연구원이 저작재산권 전부를 보유한 자료에 대한 자유이용 원칙을 설명하고, 이용 가능한 범위를 항목 본문 전체와 공공누리 표시가 있는 미디어로 안내한다. 글의 출처 표기 방식도 제시한다. 공공누리 표시가 없는 미디어는 별도 권리자의 허락이 필요하다고 명시한다.

따라서 백과사전을 일괄적으로 이용 금지 또는 퍼블릭 도메인으로 분류하지 않는다. 이번 샘플에서는 이용허락을 근거로 해설문을 가져오는 방식을 채택하지 않고, 항목을 전승·이본 확인 자료로 인용한다. 사진, 스캔, 음성 재생 기능의 음원을 샘플 자산으로 사용하지 않는다. 향후 본문·미디어를 직접 이용한다면 실제 항목과 자산별 조건·출처 표시를 다시 기록한다.

### 예산군청과 지역N문화

예산군청 자료는 역사적 배경 확인용이다. 이번 조사에서 해당 페이지의 재이용 조건을 개별적으로 확정하지 않았으므로 문장·사진 복제 근거로 사용하지 않는다. 지역N문화는 해당 설화의 제목·수록 사실까지만 직접 확인했다. 현대 교과서에 실렸다는 설명은 교과서 문장 사용 허가를 뜻하지 않는다.

### 이솝 영문 참고본

[Project Gutenberg 서지](https://www.gutenberg.org/ebooks/21)는 번역자를 George Fyler Townsend(1814–1900), 언어를 영어, 저작권 상태를 미국에서의 퍼블릭 도메인으로 표시한다. 이솝에게 전해지는 이야기와 이 특정 영문 번역을 구분한다. 전자책 공개일 2008년은 옛 번역의 창작연도가 아니다.

[본문 앞의 이용 안내](https://www.gutenberg.org/cache/epub/21/pg21-images.html)는 미국 밖에서 이용할 때 해당 국가의 법을 확인하도록 안내한다. Townsend의 사망 연도는 국내 보호기간 검토에 유용한 근거지만, 미국의 표시만으로 전 세계 권리 검토 완료를 선언하지 않는다. 이번에는 영문 파일·표지·편집물 자체를 배포하지 않고 옛 이야기 요소를 참고하여 한국어로 새로 쓴다. Project Gutenberg의 현대 자동 요약문은 원전으로 삼지 않는다.

## 3. 국내법 판단의 범위

다음은 샘플 제작의 검토 기준이며, 개별 판본에 대한 법률 확정 의견이 아니다.

- **원작과 새 번역·각색을 분리한다.** 저작권법 제5조는 창작적인 번역·각색 등의 별도 보호를 정한다. 옛 이야기라도 현대 작가가 추가한 구체적인 표현·장면 전개를 가져오면 문제가 될 수 있다. 줄거리 전체가 언제나 자유이용 대상이라는 규칙을 만들지 않는다. [국가법령정보센터 저작권법](https://www.law.go.kr/LSW/lsInfoP.do?lsId=000798)
- **기간은 판본별로 판단한다.** 제39조의 원칙은 생존 기간과 사후 70년이며, 무명·이명 저작물 등은 별도 규정이 있다. 제44조에 따라 기산 시점도 확인한다. 작자 미상이라는 표시만으로 즉시 만료를 판정하지 않는다. [저작권법 제39~44조](https://www.law.go.kr/LSW/LsiJoLinkP.do?docType=JO&joNo=004400000&languageType=KO&lsNm=%EC%A0%80%EC%9E%91%EA%B6%8C%EB%B2%95&paras=1)
- **연장 경과조치를 반영한다.** 2013년 7월 1일 전에 이미 보호기간이 끝난 저작물에는 연장 규정이 적용되지 않는다는 공식 설명을 확인했다. 사망 연도만 입력한 단순 계산으로 모든 권리를 자동 승인하지 않는다. [찾기쉬운 생활법령정보](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=2&cciNo=1&cnpClsNo=2&csmSeq=695)
- **국가별 보호를 분리한다.** 외국 저작물은 제3조와 관련 조약을 함께 검토한다. 미국 퍼블릭 도메인 표시는 국내 서비스·해외 배포의 포괄적 이용허락 증서가 아니다. [저작권법 제3조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1033063625)
- **매체별 확인을 유지한다.** 새 원고를 인쇄·웹·음성·낭독극으로 제공할 때도 삽화, 글꼴, 공연·녹음, 새 번역·각색의 권리와 계약을 각각 확인한다. 출처 링크를 붙였다는 사실만으로 이용허락을 대신하지 않는다.

## 5. 편집·배포 수용 기준

1. 10편 모두 출처 링크, 새로 쓴 판본이라는 설명, 편집 내역을 확인할 수 있다. 축약·개작을 원작 전문이나 원작 완독으로 표시하지 않는다.
2. 작성자는 현대 동화책·번역서의 문장이나 삽화를 샘플 본문·이미지 제작의 복제 재료로 사용하지 않는다. 근거 없는 고유 대사나 장면을 원전의 사실이라고 설명하지 않는다.
3. 본문 감수에서 인과관계·어휘·분량·폭력·신체 차이·지역 및 계층 편견을 확인한다. 일반 질문과 추론 질문의 답변 근거는 실제 샘플 본문에 연결한다.
4. 「혹부리 영감」의 기원 논쟁과 「의좋은 형제」의 역사·설화 구분을 교사용 설명에 유지한다. 등장인물의 대사와 새로 만든 세부는 편집적 창작임을 밝힌다.
5. 로컬 샘플에 쓰는 표지·삽화의 제작 이력과 권리를 본문과 별도로 보존한다. 기존 사이트의 그림·음성은 이 출처 조사만으로 가져오지 않는다.
6. 공개 서비스에 출시할 때 원고·시각 자산·음원·출판 범위의 권리 검수를 완료한다. 추가 과금이 발생하거나 불확실한 생성 API·음성·저장소·배포 실행은 비용과 조건을 설명한 뒤 사용자의 명시적 승인 범위 안에서만 진행한다.

이번 조사에서는 공개 웹 자료 열람과 이 문서 작성만 수행했으며, 원문 파일 수입·유료 API·음성 생성·외부 서비스 설정 변경은 수행하지 않았다.
