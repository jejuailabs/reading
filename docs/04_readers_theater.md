# 독서 기반 낭독극 PRD

- 문서 ID: PRD-04
- 상태: 설계·로컬 프로토타입 착수. 대본·수업안의 검수와 실제 학급 검증이 필요한 단계
- 기준일: 2026-11-16
- 대상: 초등 1~6학년 학급·모둠, 수업 교사
- 상위 문서: [통합 계획](../main.md)
- 연결: [읽기·질문·탐구](02_reading_inquiry_curriculum.md), [학생 공동저작](06_student_coauthoring.md)
- 인증·참여자 계약: [인증과 학교 구성원 관리](07_identity_school_management.md). 교사 화면으로 진행할 때도 학생들의 계정을 공동 사용하지 않는다.

## 1. 목적과 범위

낭독극은 학생이 대본을 보며 인물과 해설을 나누어 읽고, 이야기 이해를 목소리와 표현으로 드러내는 독서 활동으로 설계한다. 암기·의상·무대·녹음·외부 공연을 필수 조건으로 두지 않는다. 본문을 이해하고 같은 구절을 목적 있게 다시 읽는 과정이 중심이다.

목표는 원작의 인물·사건·갈등을 질문하고 해석하는 경험, 표현을 조절하며 다시 읽는 경험, 모든 학생이 참여할 역할을 얻는 경험이다. 교사의 대본 각색·배역 배분·결석 대응·자료 재편집 부담을 줄이는 것이 제품 목표다. 낭독극을 제공했다는 사실만으로 유창성·독해력 향상을 보장하지 않는다.

### 포함

- 권리가 정리되고 사람이 검수한 작품별 낭독 대본과 4·6·8인 배역안
- 학년군별 도움과 대사량 표시, 역할 순환·해설 분할·합창·짝 역할
- 원작 장면·학생 질문·표현 선택의 연결
- 교사·모둠별 배역표, 결원 대응, 인쇄·웹 동일 판본
- 원칙적으로 2차시 안에 선택 실행하는 수업안과 짧은 관찰

### 초기 범위에서 제외

- 수업 중 AI가 즉석 각색한 대본을 검수 없이 학생에게 배포
- 모든 학생의 음성을 자동 녹음·평가하거나 발음 점수로 배역 결정
- 자동 공개 공연·유튜브 업로드·보호자 외부 공유
- 교사에게 의상·소품·배경음악·촬영 편집 준비를 요구
- 낭독극 대본만 읽고 원작을 완독했다고 표시

## 2. 독서 수업과의 연결

원작 읽기·듣기에서 생긴 학생 질문을 대본 해석으로 연결한다. 예를 들어 ‘왜 도움을 거절했을까?’라는 질문에 본문 단서를 찾아 답한 뒤, 같은 대사를 화난 목소리와 두려운 목소리로 읽어 보고 어느 해석이 더 설득력 있는지 설명한다. 표현 정답을 하나로 고정하지 않는다.

원작과 각색 대본은 서로 다른 콘텐츠다. 대본에는 원작의 승인 판본, 대응 장면, 각색자, 생략·분할·추가한 표현을 기록한다. 대사가 원문 인용인지 각색인지 교사용 화면에서 구별한다. 설명을 위한 창작 대사를 원작의 사실처럼 인용하지 않는다.

낭독극은 선택 활동이다. 모든 작품에 잘 맞는다고 가정하지 않는다. 대화·갈등·인물 변화가 적거나 각색으로 의미가 크게 바뀌는 작품은 지원하지 않을 수 있다. 교사는 동일 독서목표에 맞는 짝 대화·장면 읽기 등 대체 활동을 고를 수 있다.

## 3. 학년군별 운영

| 학년군 | 권장 형태 | 도움 | 관찰 초점 |
|---|---|---|---|
| 1~2 | 교사 해설+짧은 대사, 합창·후렴, 짝이 같은 역할 읽기 | 큰 글자, 줄별 구분, 그림 역할 카드, 교사 시범, 반복 문구 | 이야기와 인물 마음을 이해하며 참여하는가 |
| 3~4 | 모둠별 장면 낭독, 역할을 바꿔 다시 읽기 | 끊어 읽기 예, 어려운 낱말, 장면별 읽기, 대사량 미리 보기 | 말·행동 근거를 들어 표현을 선택하는가 |
| 5~6 | 여러 해석 비교, 소설 장면을 낭독 대본으로 검토 | 인물 목표·갈등 표시, 원문 대조, 다른 관점으로 읽기 | 표현과 해석을 근거로 설명·수정하는가 |

읽기 속도나 발표 자신감으로 ‘주인공/못 읽는 역할’을 자동 배정하지 않는다. 모든 학생에게 의미 있는 표현 기회를 주되, 참여 방법은 교사·학생이 조정한다. 말하기를 당장 하기 어려운 학생은 짝 읽기·표현 선택·장면 연결 등으로 참여하고 이후 기회를 선택할 수 있다.

## 4. 사용자 흐름과 2차시 예시

`낭독극` 메뉴에서 검수 대본을 골라 바로 시작하거나, 독서 여정의 낭독 활동으로 들어올 수 있다. 두 경로는 같은 대본·배역·연습 화면을 사용한다. 학급·참여자·검수 대본은 필요하지만 전체 단원·온라인 완독 기록·질문 제출·과제 생성은 선행 조건이 아니다. 종이 대본과 교사 한 화면만으로도 가능하다. 연결 방식과 돌아오기·상태 보존은 [PRD 08](08_platform_architecture.md)을 따른다.

### 교사 준비

1. 읽은 작품의 승인된 낭독극 묶음을 연다.
2. 원문 대응·각색 범위·배역 수·대사량·예상 운영 시간을 미리 본다.
3. 학급을 모둠으로 구성하고 학생의 선택을 반영해 배역을 조정한다.
4. 필요한 지원을 고른 후 교사용 1장 흐름표, 모둠 대본, 배역표를 함께 출력하거나 웹으로 연다.

### 학생 활동

1. 원작에서 생긴 질문 중 인물·갈등 관련 질문을 선택한다.
2. 대응 장면을 다시 읽고 인물이 무엇을 원하는지 이야기한다.
3. 대본을 나눠 읽고 막힌 단어·장면을 확인한다.
4. 표현을 정해 연습하고 역할을 바꿔 다른 해석을 경험한다.
5. 모둠 내 또는 가까운 모둠에 짧게 읽어 준다.
6. 표현 선택의 근거와 다시 읽으며 달라진 생각을 나눈다.

### 선택 2차시 구성

| 차시 | 예시 구성 | 남기는 자료 |
|---|---|---|
| 1차시 40분 | 원작 질문·근거 확인 8분, 배역·첫 읽기 10분, 표현 비교·다시 읽기 17분, 다음 연습 결정 5분 | 모둠별 해석 질문 1개, 대본 표시 |
| 2차시 40분 | 결원·배역 확인 5분, 목적 있는 재독 10분, 모둠끼리 들려주기 15분, 근거·성찰 10분 | 선택한 표현과 근거 한 가지, 교사 간단 관찰 |

이 시간표는 설계 예시이며 효과가 검증된 표준 처방이 아니다. 2차시는 활동 범위의 상한 목표로 사용하고 원작 읽기는 별도로 충분히 확보한다. 별도 발표 준비나 가정 연습을 완료 조건으로 두지 않는다. 교사가 긴 운영을 선택한다면 실제 추가 준비·수업 시간을 명시한다.

## 5. 기능 요구사항

‘필수/확장’은 낭독극 모듈 안의 구분이며, 제품 전체의 출시 순서는 [통합 계획](../main.md)을 따른다.

| ID | 모듈 내 구분 | 요구사항 |
|---|---|---|
| RT-001 | 필수 | 대본은 원작 권리·판본·각색 권리·교육적 적합성 검토를 통과한 버전만 수업에 배포한다. 검토 중 자료는 교사 검토 화면에만 둔다. |
| RT-002 | 필수 | 모든 장면·대사 묶음에 원작 근거 위치 또는 ‘각색 추가’ 표시를 연결한다. 원문에 없는 내용을 원문 근거로 제시하지 않는다. |
| RT-003 | 필수 | 4·6·8인 검수 대본을 제공하되 실제 인원 차이는 해설 분할·합창·짝 역할·1인 다역으로 조정한다. 인원별 대본을 실시간 생성하는 것을 필수로 하지 않는다. |
| RT-004 | 필수 | 배역별 대사량·발화 차례·긴 대사 수·어려운 어휘를 교사에게 보여준다. 균형 지표는 검토 자료이며 학생 능력 평가나 자동 배역 기준이 아니다. |
| RT-005 | 필수 | 교사·학생이 배역을 바꾸고 다음 읽기에 순환할 수 있다. 수정된 배역표와 개인 표시 대본이 같은 버전으로 유지된다. |
| RT-006 | 필수 | 학생의 성별·읽기 점수로 배역을 자동 고정하지 않는다. 짧은 대사 역할에도 의미 있는 선택·표현 기회를 제공한다. |
| RT-007 | 필수 | 결원 모드는 빠진 배역을 선택하면 검수된 재분배 후보를 미리 보여준다. 교사가 확정하기 전 기존 배역표를 바꾸지 않는다. |
| RT-008 | 필수 | 결원 처리 시 학생 기록·이전 배역·기여를 삭제하지 않는다. 당일 수업용 대체와 원래 배역을 구별하고 복원할 수 있다. |
| RT-009 | 필수 | 역할 이름·기호·글자 굵기로 식별 가능하며 색상만으로 구별하지 않는다. 흑백 출력, 큰 글자, 줄 간격 조절을 지원한다. |
| RT-010 | 필수 | 교사 흐름표·모둠 대본·배역표·원문 근거를 한 묶음으로 준비하고 필요한 부분만 재출력할 수 있다. |
| RT-011 | 필수 | 낭독극에 학생 질문을 연결하고 표현 선택·근거·성찰을 선택적으로 남긴다. 사전 정답 해석과 일치해야 완료되는 조건을 만들지 않는다. |
| RT-012 | 필수 | 교사 한 화면·인쇄물만으로 진행할 수 있다. 학생 Google·개별 로그인·개인 기기·AI·마이크를 기본 요건으로 두지 않는다. |
| RT-013 | 필수 | 낭독극의 참여·완료와 원작의 읽기·듣기 기록을 구분한다. 대본 완료로 원작 완독을 자동 확정하지 않는다. |
| RT-014 | 필수 | 관찰은 근거 있는 표현, 협력·경청, 다시 읽으며 조정하기 중 선택한다. 연기력·목소리 크기·읽는 속도의 공개 점수표를 제공하지 않는다. |
| RT-015 | 필수 | 단원/여정과 `assignment_id`는 선택 연결이다. 단독 낭독 활동을 나중에 여정에 연결할 수 있다. 제출이 필요한 경우에도 모둠의 짧은 성찰이나 교사 확인으로 충분하며 음성·영상 제출을 의무화하지 않는다. |
| RT-016 | 확장 | 검수된 시범 음성이 있는 경우 선택 재생한다. 대본 판본이 바뀌면 음성 일치 여부를 확인하고 불일치 자료를 자동 재생하지 않는다. |
| RT-017 | 확장 | 교사 요청에 따라 AI 각색 초안을 만들 수 있으나 비용 승인·권리 조건·교사 검토를 모두 거쳐 새 대본 버전으로 취급한다. 초기 핵심 흐름은 이 기능에 의존하지 않는다. |
| RT-018 | 필수 | 공유는 해당 학급 내부가 기본이다. 음성 녹음·외부 공개·공연 전송은 자동 실행하지 않으며 초기 버전에 원클릭 외부 공개를 넣지 않는다. |

### 대본 검수 항목

- 원작의 인물 목표·사건 인과·결말을 각색이 왜곡하지 않는가
- 원문 인용과 새 대사가 구별되는가
- 한 인물의 독백을 해설로 분할할 때 의미가 유지되는가
- 역할 수와 실제 발화 기회가 맞는가; 짧은 역할을 맡은 학생의 참여 방법이 있는가
- 읽기 수준 지원이 낙인으로 표시되지 않는가
- 고전의 차별적 표현·폭력·시대 배경이 학년군에 맞게 설명되는가
- 교사가 새 소품·그림·음원을 준비하지 않고 실행할 수 있는가
- 2차시 예시의 시간을 넘는다면 어떤 활동이 추가되는지 명시했는가

## 6. 데이터와 접근 범위

독립 `reading` 서비스의 목표 저장 구조는 Firebase Auth·Firestore·Cloud Storage이며 세부 계약은 [PRD 08](08_platform_architecture.md)을 따른다. 현재 로컬 프로토타입은 데이터 어댑터와 합성 배역·참여자만 사용하며 실제 Firebase에는 연결하지 않는다. 이 PRD는 외부 서비스를 개설하거나 호출하지 않는다. 아래 엔터티는 논리적 데이터 계약이다.

학급 낭독 운영 문서는 모두 `school_id`·`class_id`를 가진다. Firebase Auth로 신원을 확인한 뒤 서버는 최신 membership의 학교·학급 소속·역할·활성 상태를 확인하여 배역·관찰·결원 데이터의 조회·수정을 허용한다. Firestore·Storage Security Rules도 해당 접근 범위를 검증한다. 오래된 토큰 클레임이나 클라이언트가 보낸 ID만으로 허용하지 않으며 서버 자체 검증을 생략하지 않는다. 로컬 역할 전환·결원 복구 시연은 이 흐름의 UX 검증이며 실제 Rules·접근 철회 검증은 Firebase 연동 후 수행한다.

| 엔터티 | 주요 필드 | 정책 |
|---|---|---|
| theater_sessions | id, school_id, class_id, unit_id?, activity_id, script_revision_id, assignment_id?, mode, status | 해당 학급 교사와 배정된 참여자. 단독 실행도 동일한 권한 |
| script_assignments | session_id, school_id, class_id, group_id, approved_variant_id, allocation_revision | 모둠별 배정된 대본만 학생 접근 |
| theater_casts | session_id, school_id, class_id, group_id, learner_profile_id, role_ids, paired_role, rotation_round | 교사가 조정. 학급 밖 명단 접근 금지 |
| cast_revisions | school_id, class_id, session_id, revision, reason_code, previous_revision, confirmed_by | 결원·순환 변경 이력. 실제 결석 사유 자유 텍스트는 수집하지 않음 |
| theater_interpretations | school_id, class_id, group_id, source_question_id?, scene_anchor_ids, chosen_expression?, evidence_refs, reflection? | 해당 모둠·교사. 학급 공유는 명시적 선택 |
| theater_observations | school_id, class_id, learner_profile_id, criterion_codes, note?, evidence_ref, status, confirmed_by? | 교사 전용 원칙. 수동 최종 확정 |

공통 검수 대본과 학급 운영 기록은 분리한다. 공용 콘텐츠에 학급 이름·학생 배역을 합쳐 공개 파일로 저장하지 않는다. 개인 표시 PDF는 비공개 산출물로 취급한다. 녹음 저장은 초기 핵심 범위에서 제외하며 추후 도입 시 보관·삭제·접근·공유 정책을 별도 확정한다.

### 이벤트 계약

공통 필드: `event_id`, `schema_version`, `event_type`, `occurred_at`, `received_at`, `school_id`, `class_id`, `actor_profile_id`, `resource_type`, `resource_id`, `revision_id`, `request_id`, `trace_id`, `outcome`, `source`, `metadata_allowlist`.

배역의 실명, 결석자 이름·사유, 낭독 음성, 학생 해석·성찰 원문, 교사 평가 서술을 이벤트·오류 로그에 넣지 않는다. `source`는 `web`/`paper`/`teacher_import`이며 종이 활동은 세부 로그가 없어도 정상 참여다. 초 단위 행동 감시·음성 분석을 기능 사용의 전제로 하지 않는다.

## 8. 검증·수용 기준

| ID | 대상 | 통과 조건 |

| RT-AC-02 | RT-003~008 | 4·6·8인안과 홀수·결원 시나리오에서 모든 배역이 처리되고 학생 배역·이전 기여가 삭제되지 않는다. 변경 전 미리 보기와 복원이 가능하다. |
| RT-AC-03 | RT-004~006 | 교사가 대사량과 배역 순환을 확인·수정할 수 있으며 성별·읽기 점수로 자동 배역을 고정하지 않는다. |
| RT-AC-04 | RT-009~010 | 흑백 출력에서 역할이 구별되고 잘린 대사·역할 표기가 없다. 웹·개인 대본·모둠 대본이 동일 판본이다. |
| RT-AC-05 | RT-011~014 | 학생 질문→원문 근거→표현 비교→성찰 흐름을 수행한다. 대본 읽기로 원작 완독을 자동 기록하지 않는다. |
| RT-AC-06 | RT-012,015 | 학생 계정·개인 기기·AI·녹음 없이 수업과 과제 확인을 마칠 수 있다. 종이 참여는 미제출로 자동 처리하지 않는다. |
| RT-AC-07 | RT-016~017 | 판본이 다른 음성과 미검수 AI 대본은 자동 배포되지 않는다. 비용·권한 미확인 상태에서 외부 생성 요청이 발생하지 않는다. |
| RT-AC-08 | RT-018, 데이터 | 다른 학급·학교·권한 철회 사용자는 배역표·개인 대본·관찰에 접근하지 못한다. 파일 URL도 같은 범위를 지킨다. |
| RT-AC-09 | 이벤트 | 실명·결석 사유·음성·성찰·평가 원문이 추적·오류·분석 이벤트에 존재하지 않는다. |
| RT-AC-10 | 운영 | 실제 파일럿에서 대본 편집·배역·인쇄·문제 대응·평가 시간을 합산한다. 2차시 안에 운영되지 않은 이유를 기록하고 추가 노동을 숨기지 않는다. |

학습 검증은 낭독 속도 하나가 아니라 정확성·표현·이해·참여를 구분한다. 시범의 따라 읽기 성공을 새로운 글의 독립 읽기 향상으로 해석하지 않는다. 교사 관찰과 학생 설명을 함께 보며, 작은 표본의 전후 변화만으로 인과효과를 주장하지 않는다.

## 9. 출처와 근거 한계

1. [Reading Rockets, Readers Theater](https://www.readingrockets.org/classroom/classroom-strategies/readers-theater): 대본을 보며 목적 있게 반복 읽는 실무 안내. 검색 본문을 확인했으며 직접 페이지 접근에는 제한이 있었다. 특정 한국어 제품의 효과 근거는 아니다.
2. [IES/WWC, 4~9학년 읽기 지원 가이드](https://ies.ed.gov/ncee/wwc/PracticeGuide/29): 목적 있는 유창성 활동·반복 읽기에 관한 근거. 이 PRD의 2차시 낭독극 전체를 검증한 연구가 아니다.
3. [유보라, 2024, 낭독극을 활용한 읽기 유창성 지도 방안](https://literacy.knue.ac.kr/article.brd/_36.37.655965/%EB%82%AD%EB%8F%85%EA%B7%B9%EC%9D%84%20%ED%99%9C%EC%9A%A9%ED%95%9C%20%EC%9D%BD%EA%B8%B0%20%EC%9C%A0%EC%B0%BD%EC%84%B1%20%EC%A7%80%EB%8F%84%20%EB%B0%A9%EC%95%88.pdf): 초3 18명, 3주 8차시의 단일집단 사전·사후 연구. 원문을 확인했다. 개선 보고는 있으나 통제집단이 없어 모든 변화를 낭독극의 효과로 단정할 수 없다.
4. [Mastrothanasis 외, 2023, Readers Theatre 연구 종합](https://www.sciencedirect.com/science/article/pii/S2666374023000183): 체계적 고찰 23개 연구, 메타분석 11개 연구에서 긍정적 읽기 효과를 보고. 검색·초록 수준 확인이며 직접 원문 접근은 제한됐다. 언어·표본·실행 조건 차이와 전체 원문 미확인 한계를 유지한다.
5. [이지영, 2019, 초등교사의 온책읽기 딜레마](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002487255): 시간 배정·읽기 속도·읽기 방법·활동 목적에 관한 교사 고민. 이 제품의 업무 절감 수치를 증명하지 않는다.

4·6·8인 구성, 결원 처리, 2차시 수업안, 최소 관찰 항목은 제품 설계 제안이다. 대본별 사람 검수와 실제 학급 운영으로 적합성을 확인한다.
