# PRD 03 도서관과 읽기 매체 및 권리

[전체 설계로 돌아가기](../main.md)

작성일: 2026-11-16 · 상태: 설계·로컬 프로토타입 착수 · 요구사항 접두사: LIB

현재 프로토타입은 로컬 데이터 어댑터와 창작 데모 판본을 사용하며 실제 Firebase Auth·Firestore·Cloud Storage에는 연결하지 않는다. 권리·공개 범위·읽기 위치 등 화면 흐름을 확인하되, 실제 인증·Rules·비공개 파일 접근 통제의 검증으로 간주하지 않는다. 구현 계약은 [PRD 08](08_platform_architecture.md)을 따른다.

## 1. 목적과 범위

검토된 한 작품을 인쇄본·온라인·오디오에서 같은 내용과 위치로 제공한다. 교사가 판본을 맞추거나 권리 조건을 매번 조사하지 않아도 수업을 준비하도록 한다. 고전·교사 제작·학생 공동 저작을 같은 출판 구조로 관리하되 권리 상태와 공개 범위는 각각 판단한다.

학교가 이미 가진 현대 도서는 서지·수업안·학생 질문을 연결할 수 있다. 전문 탑재·스캔·음성화를 허가받지 않았다면 본문 제공 버튼을 만들지 않는다. 도서관 대출과 실제 책을 활용하는 수업도 정상 경로다.

`서재`는 표지·검색·필터로 고르는 화면이고, 책을 열면 본문 중심의 몰입형 리더로 전환한다. 서재에서 직접 읽거나 이야기 여정·질문의 근거 링크로 읽어도 같은 판본과 리더를 사용한다. 독립 읽기에 과제/여정 ID를 요구하지 않으며 듣기·어휘·인쇄·질문 남기기는 필요한 보조 도구로 제공한다. 수업에 연결할 때만 활동 맥락을 추가하고 다른 수업의 답변·관찰은 가져오지 않는다. [PRD 08](08_platform_architecture.md)의 메뉴·연결·복원 규칙을 따른다.

## 2. 콘텐츠의 단위와 상태

```text
work 작품
  └─ edition 판본: 언어·번역/개작·편집 기준·권리
      └─ edition_revision 고정본
          ├─ chapter / scene / paragraph 본문 위치
          ├─ PDF / EPUB / 웹 읽기
          ├─ 삽화 / 대체텍스트
          ├─ 음성 / 구간 시간표
          ├─ 교사 질문 / 학생 질문의 참조 위치
          └─ 낭독극 / 수업안 / 관찰 기준
```

판본 상태: `draft → rights_review → editorial_review → ready → published → retired`.

권리 상태는 별도로 `unverified / restricted / cleared / disputed / expired_permission`을 둔다. 편집 검수가 끝나도 권리가 미확인인 파일은 배포할 수 없다. 이미 배포한 고정본을 직접 덮어쓰지 않고 새 revision을 만든다.

원문·표기 현대화본·쉬운말 개작본·축약본·낭독극을 구별한다. 축약본이나 일부 장면을 원작 전문·원작 완독으로 표시하지 않는다. 작품을 부분 발췌할 때도 분량과 원작 내 위치를 표시한다.

## 4. 권리 판단과 콘텐츠 입고

개인 저작물의 일반적인 저작재산권 보호기간은 생존 기간과 사후 70년이다. 다만 2013-07-01 이전 이미 만료된 권리가 부활하지 않는 경과조치가 있으므로 사망 연도 하나만으로 자동 판정하지 않는다. 번역·개작·삽화·음원·실연은 별도로 확인한다. [한국저작권위원회](https://www.copyright.or.kr/information-materials/common-sense/basic-knowledge/index.do?jspName=08), [생활법령 경과조치](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=2&cciNo=1&cnpClsNo=2&csmSeq=695)

학교 수업 목적의 이용 예외를 민간 서비스의 도서 전문 제공에 대한 포괄 허락으로 해석하지 않는다. 수업 범위·공개 범위·자료 종류에 따라 별도 판단이 필요하다. [저작권법](https://www.law.go.kr/법령/저작권법)

## 5. 도서 선택과 수업 묶음

LIB-007: 도서 카드에 학년 권장 범위, 실제 글자/장/쪽 수, 예상 지원 수준, 주제, 갈등, 등장인물, 어려운 어휘, 정서적 주의 장면, 원문/개작 구분, 지원 언어·음성, 필요한 기기·인쇄량을 표시한다. 예상 읽기 시간은 추정값으로 표시하고 교사가 조정한다.

LIB-008: 학년·기기·남은 차시·흥미 조건으로 2~3개 선택지를 보여준다. 학생이 교사가 추린 선택지에서 의견을 내거나 투표할 수 있다. 선택 결과가 소수 학생의 접근을 배제하면 교사가 조정한다.

LIB-009: 수업 묶음은 교사용 한 장 흐름표, 본문, 선택 질문, 학생 질문 공간, 선택 낭독극, 선택 창작 틀, 짧은 관찰표로 구성한다. 활동지를 모두 출력하는 것을 기본값으로 삼지 않는다.

오디오를 읽기 이해의 보조 수단으로 사용한다. 30개 연구·1,945명 메타분석은 듣기 병행의 전체 이점이 작고 자기 속도로 읽는 조건에서는 확실한 이점을 찾지 못했다고 보고했다. 따라서 모든 학생에게 듣기를 강제하거나 재생 완료를 독해 향상으로 표시하지 않는다. [Clinton-Lisell 2023](https://commons.und.edu/ehb-fac/75/)

문자 해독·유창성·내용 이해는 구분한다. 듣기로 이야기에 참여한 아이도 같은 질문·토론에 참여하며, 필요한 문자 읽기 지원은 별도로 제공한다.

## 7. 인쇄물을 책으로 제공하기

- LIB-019: 기본은 A4 순차 출력 PDF, 선택은 A5 소책자 조판 PDF다. 프린터 설정을 확인할 1장 시험 출력 안내를 제공한다.
- LIB-020: 흑백·잉크 절약·큰 글자 판형을 제공한다. 그림이 어두운 덩어리가 되지 않는지 실제 인쇄로 검토한다.
- LIB-021: 표지·목차·쪽번호·판본번호·출처·읽기용 여백을 제공하고, 본문과 소모성 활동지를 분리한다.
- LIB-022: 장면 QR은 읽기/듣기 위치로 연결한다. QR 자체에 학생 ID·토큰·개인정보를 넣지 않는다. 비공개 책은 로그인·수업 접근 검사를 다시 한다.
- LIB-023: 분실한 쪽·장면만 재출력하고, 합본을 단원 시작에 한 번 배부할 수 있게 한다.
- LIB-024: 제본 없이 파일철·접기 형태로도 수업이 가능하다. 교사가 수십 권을 직접 제본해야만 기능이 성립하지 않도록 한다.
- LIB-025: 인쇄 전 총 쪽수, A4 예상 장수, 부수, 컬러 여부를 보여준다. 실제 프린터·표지·여백 조건에 따라 달라질 수 있음을 표시한다.

계산 예: 총 48쪽 A5 소책자를 A4 한 장의 양면에 4쪽씩 배치하면 1권 12장, 30명은 360장이다. 종이·토너·제본·배부의 비용과 시간을 무료 콘텐츠와 별도로 평가한다.

## 8. 언어·판본·배포

UI 언어를 바꿔도 책의 언어를 자동 번역하지 않는다. 번역은 별도 판본이며 번역문·그림·질문·음성의 검수와 권리가 필요하다. 원문과 번역을 병렬로 볼 때 대응 장면을 연결하되 문단이 1:1이라고 가정하지 않는다.

웹 읽기본과 인쇄본에는 같은 판본명·revision을 표시한다. 출판 후 본문이 바뀌면 연관된 질문·대본·음성을 `stale`로 표시하고 영향받는 부분만 검토·재생성한다. 이미 시작한 수업은 기존 revision에 고정해 쪽번호가 갑자기 바뀌지 않게 한다.

공개 도서관에는 권리 검증·비식별·편집 승인된 콘텐츠만 둔다. 교사 초안은 본인·초대한 검토자, 학생 초안은 본인/지정 모둠·담당 교사만 접근한다. 학급 공개는 검토한 고정본에 명시적으로 승인하며, 학교·외부 공개도 별도 범위와 권리·동의 절차를 거친다. 저장·생성 완료만으로 공개 범위를 확대하지 않는다.

## 9. 데이터와 이벤트

업무 데이터: `works`, `editions`, `edition_revisions`, `text_blocks`, `assets`, `audio_segments`, `rights_records`, `publication_reviews`, `reading_positions`, `annotations`, `export_jobs`.

위 이름은 논리적 엔터티다. 향후 구조는 Firebase Auth로 신원을 확인하고 Firestore 업무 문서와 Cloud Storage 자산을 사용한다. 검수된 공개 도서와 학교·학급별 비공개 자료의 접근 경로를 분리하며, 학생 읽기 위치·주석에는 `school_id`·`class_id`를 유지한다. 서버는 최신 membership의 소속·역할·활성 상태 및 해당 자산의 공개·권리 상태를 확인하고, Firestore·Storage Security Rules도 허용 경로의 접근 범위를 검증한다. 로그인 성공·오래된 토큰 클레임·파일 URL을 알고 있다는 사실만으로 비공개 자료 접근을 허용하지 않는다. 구체 경로·공개 자산 배포 방식·서버 검증은 [PRD 08](08_platform_architecture.md)에 따른다.

주요 이벤트: `library.book_selected`, `reader.opened`, `reader.mode_changed`, `reader.position_saved`, `reader.annotation_created`, `audio.playback_failed`, `export.requested/completed/failed`, `edition.published/retired`, `rights.status_changed`.

원문 주석·질문·학생 음성은 보호된 업무 문서/비공개 파일에 저장한다. 이벤트에는 식별자·매체·revision·결과만 담고 내용 전체를 복제하지 않는다. 종이 참여는 교사가 간단히 기록할 수 있으나 모든 종이를 전산화하지 않는다.

## 10. 수용 기준과 실패 처리

1. LIB-AC01: 같은 revision의 PDF·웹·오디오·질문에서 임의로 고른 장면 10곳의 내용·위치가 맞는다.
2. LIB-AC02: 인쇄 권한 없는 책은 URL 직접 호출로도 PDF를 얻지 못한다.
3. LIB-AC03: 큰 글자/번역판의 쪽수가 달라도 질문은 안정적인 장면·문단 참조로 연결된다.
4. LIB-AC04: 음성 오류 시 본문 읽기·종이 수업으로 계속 진행할 수 있다.
5. LIB-AC05: 미검수 번역·음성·새 revision은 이미 배포된 학급 책을 자동 교체하지 않는다.
6. LIB-AC06: 학생 계정 없이도 교사 주도 종이 수업이 가능하고 개인 기록을 사칭해 생성하지 않는다.
7. LIB-AC07: 권리 분쟁 발생 시 새 공개·내보내기를 차단하고 영향 범위와 이미 내려받은 파일의 회수 한계를 확인할 수 있다.
8. LIB-AC08: 읽기시간·완독 자기보고·듣기 완료·교사 관찰이 서로 다른 지표로 저장된다.

## 11. 우선순위

P0: 소수 권리 검수 작품, A4·A5 출력, 웹 읽기, 검수 음성, 위치·어휘·질문 연결, 교사 화면 모드.

P1: EPUB, 다양한 판형, 번역 병렬 읽기, 판본별 수업 묶음 확대, 승인된 오프라인 패키지.

P2: 출판사 정식 라이선스와 보유 도서 연계 확대. 외부 카탈로그 계약·과금은 별도 승인 후 추진한다.
