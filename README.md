# 온책읽기

[서비스 열기](https://reading-bice-six.vercel.app) · [GitHub 저장소](https://github.com/jejuailabs/reading)

2026-11-16에 `jejuai/reading`으로 첫 프로덕션 배포를 완료했다. 배포된 앱 소스는 `6aa8393`이며, [배포 후 검증](artifacts/production-verification.md)에서 읽기·기존 음원 재생·책과 활동지 PDF 다운로드를 확인했다. 현재 기기 저장형 미리보기이며 Firebase 로그인·서버 동기화·운영 AI는 연결되지 않았다.

이번 승인 범위는 초기 배포 1회와 공개 호스팅이다. `vercel.json`의 `git.deploymentEnabled: false`로 이후 Git push가 추가 유료 빌드를 자동 실행하지 않도록 한다. 다음 배포는 비용 범위를 승인받은 뒤 수동 실행한다. `.vercelignore`는 향후 CLI 배포에 앱 실행·빌드 파일만 포함하도록 제한한다.

책을 가져와 읽고 듣고, 자기 질문과 생각을 기록하고, 새 책을 만들어 다시 읽는 초등 독서 공간입니다. 사용자가 선택한 밝은 색연필 그림과 흰 여백을 디자인 기준으로 삼습니다.

현재는 **브라우저 IndexedDB에 보관하는 로컬 작업 공간**입니다. 실제 학교 계정·Firebase 클라우드 저장·실시간 공동 편집은 연결되지 않았습니다. 역할 선택은 화면 미리보기이며 서버 권한이 아닙니다.

- [학교 수업 매뉴얼](docs/16_school_book_manual.md): 책 가져오기 → 읽기 → 질문 → 기록지·PDF
- [책 공방 매뉴얼](docs/manual-bookmaking.md): 교사·개인·팀의 단계별 저작
- [전체 설계](main.md), [온책읽기 확장 계약](docs/14_wholebook_implementation_brief.md), [20양식·출력 계약](docs/15_report_templates_pdf_print.md)
- [GitHub → Vercel 배포 준비](docs/17_github_vercel_release.md): 사용자 지정 `jejuailabs/reading`, `main`

## 실행

Node.js 22.21.0 환경에서 개발했습니다. 기존 작업 공간에서는 `npm run dev`를 실행하고 [http://127.0.0.1:3100](http://127.0.0.1:3100)을 엽니다. 처음 설치하는 곳은 먼저 `npm ci`를 실행합니다. 로컬 주소이므로 기본적으로 다른 기기에 공개하지 않습니다.

## 빠른 체험

1. **서재 → 내 책 가져오기**에서 짧은 원고를 입력하고 검토합니다. `---`로 장면을 나눕니다.
2. **책만 읽기**에서 글만 보기·책갈피를 사용하고 **내 질문**을 남깁니다.
3. **온책읽기·기록지**에서 질문·근거·생각 양식을 만들고 자기 질문을 가져옵니다.
4. 필요한 칸을 자기 말로 채우고 **작성 내용 PDF**를 누릅니다. **빈 양식 PDF**에는 답변·그림이 없습니다.
5. **책 만들기**에서 주제·유형·장수를 정하고 글·그림을 편집합니다. 검토 후 **고정 판본으로 서재에 놓기**를 선택합니다.
6. 새 책을 읽고 기록하거나, **사용 안내 → 전체 작업 백업**으로 수정 가능한 자료를 보관합니다.

## 입력과 AI가 아는 범위

텍스트 PDF는 기기에서 추출하며 20MB·100쪽·20만 자 한도를 적용합니다. 스캔 PDF OCR은 없습니다. 페이지 그림은 보기용이며 그림 속 글자를 자동 인식하지 않습니다. 링크/종이책 등록만으로 본문을 읽었다고 처리하지 않습니다. 등록 전에 추출된 글·장면·권리·전체/발췌 범위를 확인합니다.

문항별 AI 힌트는 현재 한 장면과 선택한 양식 문항을 사용합니다. 학생 자신의 질문을 우선하며 답변을 자동으로 채우지 않습니다. 본문이 없으면 이 기능을 실행하지 않습니다. 학년군 선택만으로 모든 양식을 자동 재작성하지는 않습니다.

## 보관과 팀 작업

IndexedDB `onbook-device-workspace`에서 읽기 상태·책 공방·학습 기록장을 보관합니다. 이전 localStorage/sessionStorage는 원본을 유지하고 이전합니다. 오래된 탭이 최신 저장을 덮어쓰지 못하도록 충돌을 감지합니다. 저장 오류가 보이면 현재 화면의 JSON 백업을 먼저 받습니다.

브라우저 데이터 삭제·기기 교체·사생활 보호 모드·용량 제한까지 보존을 보장하지 않습니다. `/guide`의 전체 백업은 세 저장소를 포함하며, 복원은 **병합이 아닌 해당 저장소 교체**입니다. 파일 검증 후 현재 자료의 백업을 먼저 내려받도록 요청하고 하나의 트랜잭션으로 복원합니다. 공방/기록장의 개별 JSON 백업은 전체 복원 파일과 다른 형식입니다.

팀은 한 기기를 순서대로 사용하며 별명·역할·작성자·기여·피드백을 남깁니다. 실제 계정별 인증이나 다중 기기 동시 편집은 아닙니다. 장수 변경은 기존 원고를 보존한 복사본을 만들고 완성 판본은 이후 초안 수정과 분리합니다.

## PDF·듣기

React PDF와 로컬 Nanum Gothic 글꼴로 실제 PDF 파일을 생성합니다. A4/A5, 긴 글의 자동 쪽 증가, 그림 응답, 책 전체 페이지를 지원합니다. PDF는 출력용이며 편집 데이터는 JSON으로 보관합니다. 브라우저 기록지 인쇄는 이름 있는 A4 규칙으로 분리했습니다. 학급 일괄 합본·중철 면배치·EPUB은 아직 없습니다.

고전 10편은 프로젝트를 위해 새로 쓴 한영 재서술본입니다. [작품과 출처](docs/11_classic_sample_sources.md)를 확인하세요. 장면별 한영 기기 낭독 100개와 승인받아 생성한 한국어 전권 AI 낭독 10개를 저장 파일로 재생합니다. 재생 시 생성 API를 호출하지 않습니다. 전권 음성과 장면의 자동 동기화는 없습니다. 가져온 원고·새 책은 설치된 `localService` 기기 음성이 있을 때 읽습니다. PDF에는 음성이 들어가지 않습니다. [낭독 기록](docs/13_ai_narration.md)

## 비용·연결 경계

기존 텍스트 AI 파일럿은 OpenAI GPT-6 Luna, 개발 검증 최대 10회·US$1, 2026-11-17 11:49 KST까지입니다. 양식 힌트도 같은 원장·한도를 따릅니다. 이번 문항 확장은 모의 응답으로 검증했고 실제 신규 호출은 없습니다. 이전 실제 텍스트 호출 2회와 TTS 10회는 각각 기존 승인 기록입니다. 자동 재시도·유료 모델 우회·자동 충전·새 구독은 없습니다. 프로덕션에서는 파일럿 API를 차단합니다.

책 삽화 API 준비 코드는 기본 비활성이며 실제 호출은 없습니다. **사용자 지시에 따라 이번 디자인 이미지는 구독 내장 imagegen만 사용하며 별도 이미지 API/프로젝트 API 키를 사용하지 않습니다.** 디자인용 16회 승인은 앱 런타임 삽화 API의 승인이 아닙니다. 그림체/요청문 선택만으로 이미지를 생성했다고 표시하지 않습니다.

운영 목표는 **GitHub `jejuailabs/reading` → 독립 Vercel + Firebase**입니다. 실제 연결·권한·요금을 확인한 뒤 해당 범위로 배포합니다. `.env.local`, 서비스 계정, `.local` 비용 원장은 커밋하지 않습니다. Firebase 설정 보유는 실제 연결이나 추가 과금 승인이 아닙니다. **homework의 코드·DB·인증·키·배포는 수정하거나 연결하지 않습니다.**

미구현 운영 범위: Google/Firebase 로그인과 학교 서버 권한, 실제 관리자, 클라우드 저장, 실시간 공동저작, 공개 공유·동의 관리, OCR, 링크 본문 자동 수집, 완성책 자동 생성, 모든 책의 자동 낭독극 변환, 불변 감사 로그. PRD 목표와 구현 완료를 구별합니다.

## 검증

```powershell
npm run typecheck
npm test
npm run build
```

`prebuild`는 PDF.js 워커를 로컬 정적 경로에 복사합니다. `npm run start`는 빌드된 앱의 로컬 실행이며 클라우드 배포가 아닙니다. [학교 책 워크플로 검증](artifacts/school-book-verification.md)에 실제 통과 범위와 한계를 기록합니다.

주요 코드: `book-intake.tsx`/`pdf-intake.ts`, `reader-tools.tsx`, `learning-hub.tsx`/`report-templates.ts`, `book-workshop.tsx`/`book-workshop-model.ts`, `pdf-export.ts`, `device-storage.ts`/`workspace-store.ts`/`workspace-backup.ts`. 기존의 사용하지 않는 localStorage 저장 어댑터는 공통 IndexedDB 훅으로 통합했습니다.
