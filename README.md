# 온책읽기

[서비스 열기](https://reading-bice-six.vercel.app) · [GitHub 저장소](https://github.com/jejuailabs/reading)

**현재 소스:** 설명형 랜딩페이지, Google 로그인, 서버 세션과 역할 검사, 체험 교실과 계정별 작업 공간 분리를 구현했다. 해당 구현은 106개 테스트와 프로덕션 빌드를 통과했고, 로컬에서 실제 `accounts.google.com` 로그인 페이지 진입을 확인했다. 첫 업데이트 배포에서 발생한 서버 모듈 호환 오류를 수정했으며, 수정 후 빌드와 오프라인 프로덕션 실행 검사 9개를 통과했다. 수정본의 추가 배포 1회는 아직 승인·실행하지 않았다. 실제 계정 로그인 완료·재접속·로그아웃 검증도 남아 있다.

**현재 공개 사이트:** 이전 앱 소스 `6aa8393`으로 복구한 상태다. 2026-11-16 16:04 KST에 승인된 업데이트 `7b66690`을 배포했지만, 빌드 `READY` 이후 서버에서 `ERR_REQUIRE_ESM`과 HTTP 500이 발생했다. 새 빌드 없이 Instant Rollback으로 이전 배포를 복원하고 첫 화면을 확인했다. 따라서 공개 사이트에는 이번 랜딩·로그인 변경이 아직 적용되어 있지 않다. [장애·복구·수정 검증 기록](artifacts/auth-landing-verification.md)과 [초기 배포 검증](artifacts/production-verification.md)을 구분한다.

초기 배포와 별도로 승인받은 업데이트 1회는 위 배포에서 사용했다. reading의 Production 환경에 인증 변수 12개를 설치했으며, 수정본을 다시 배포하기 전 추가 1회의 비용 범위를 승인받는다. `vercel.json`의 `git.deploymentEnabled: false`로 Git push가 추가 유료 빌드를 자동 실행하지 않도록 한다. `.vercelignore`는 CLI 배포에 앱 실행·빌드 파일만 포함하도록 제한한다.

책을 가져와 읽고 듣고, 자기 질문과 생각을 기록하고, 새 책을 만들어 다시 읽는 초등 독서 공간입니다. 사용자가 선택한 밝은 색연필 그림과 흰 여백을 디자인 기준으로 삼습니다.

현재 작업 자료는 **브라우저 IndexedDB에 계정별로 보관**합니다. Google 인증과 서버 세션은 구현했지만, Firestore·Storage의 업무 데이터 저장, 학교 명부 연동, 기기 간 동기화와 실시간 공동 편집은 아직 제공하지 않습니다. 역할 선택은 `/demo`의 체험 기능에만 남아 있으며 실제 계정 권한은 서버가 확인한 `reading_role`을 따릅니다.

## 실행

Node.js 22.21.0 환경에서 개발했습니다. 기존 작업 공간에서는 `npm run dev`를 실행하고 [http://127.0.0.1:3100](http://127.0.0.1:3100)을 엽니다. 처음 설치하는 곳은 먼저 `npm ci`를 실행합니다. 로컬 주소이므로 기본적으로 다른 기기에 공개하지 않습니다.

## 구현된 화면

아래는 이번 소스 변경의 경로입니다. `{공간}`은 로그인 없이 사용하는 `demo` 또는 로그인한 계정의 `app`입니다. 기존 `/library`, `/reader/{bookId}` 등은 호환성을 위해 `/demo/...`로 연결됩니다. 내 계정의 작업은 `/app` 안의 메뉴로 엽니다.

## 빠른 체험

첫 화면에서 **로그인 없이 체험하기**를 선택합니다. 체험 안내의 읽기·듣기 → 자기 질문 → 기록지 PDF → 낭독극 → 책 만들기를 직접 열어 보거나, 아래처럼 내 원고로 시작할 수 있습니다. 로그인 후 사용하는 공간에도 같은 책 활동이 있으며 체험 자료와 계정 자료는 분리됩니다.

1. **서재 → 내 책 가져오기**에서 짧은 원고를 입력하고 검토합니다. `---`로 장면을 나눕니다.
2. **책만 읽기**에서 글만 보기·책갈피를 사용하고 **내 질문**을 남깁니다.
3. **온책읽기·기록지**에서 질문·근거·생각 양식을 만들고 자기 질문을 가져옵니다.
4. 필요한 칸을 자기 말로 채우고 **작성 내용 PDF**를 누릅니다. **빈 양식 PDF**에는 답변·그림이 없습니다.
5. **책 만들기**에서 주제·유형·장수를 정하고 글·그림을 편집합니다. 검토 후 **고정 판본으로 서재에 놓기**를 선택합니다.
6. 새 책을 읽고 기록하거나, **사용 안내 → 전체 작업 백업**으로 수정 가능한 자료를 보관합니다.

## 입력과 AI가 아는 범위

텍스트 PDF는 기기에서 추출하며 20MB·100쪽·20만 자 한도를 적용합니다. 스캔 PDF OCR은 없습니다. 페이지 그림은 보기용이며 그림 속 글자를 자동 인식하지 않습니다. 링크/종이책 등록만으로 본문을 읽었다고 처리하지 않습니다. 등록 전에 추출된 글·장면·권리·전체/발췌 범위를 확인합니다.

문항별 AI 힌트는 현재 한 장면과 선택한 양식 문항을 사용합니다. 학생 자신의 질문을 우선하며 답변을 자동으로 채우지 않습니다. 본문이 없으면 이 기능을 실행하지 않습니다. 학년군 선택만으로 모든 양식을 자동 재작성하지는 않습니다.

## 보관과 팀 작업

IndexedDB `onbook-device-workspace`에서 읽기 상태·책 공방·학습 기록장을 보관합니다. 체험 자료는 기존 저장 키를 유지하고, 계정 자료는 Firebase UID를 바탕으로 분리합니다. 이전 localStorage/sessionStorage의 체험 자료는 원본을 유지하고 이전하며, 계정 공간에 자동으로 섞지 않습니다. 오래된 탭이 최신 저장을 덮어쓰지 못하도록 충돌을 감지합니다. 저장 오류가 보이면 현재 화면의 JSON 백업을 먼저 받습니다.

브라우저 데이터 삭제·기기 교체·사생활 보호 모드·용량 제한까지 보존을 보장하지 않습니다. 각 공간의 `guide`에서 받는 전체 백업은 해당 공간의 세 저장소를 포함하며, 복원은 **병합이 아닌 해당 저장소 교체**입니다. 파일 검증 후 현재 자료의 백업을 먼저 내려받도록 요청하고 하나의 트랜잭션으로 복원합니다. 다른 계정이나 데모 저장소를 함께 교체하지 않습니다. 공방/기록장의 개별 JSON 백업은 전체 복원 파일과 다른 형식입니다.

팀은 한 기기를 순서대로 사용하며 별명·역할·작성자·기여·피드백을 남깁니다. Google로 로그인한 사용자와 공방에 적는 팀원 별명은 별개이며, 팀원 각자의 동시 접속이나 다중 기기 공동 편집은 아직 제공하지 않습니다. 장수 변경은 기존 원고를 보존한 복사본을 만들고 완성 판본은 이후 초안 수정과 분리합니다.

Google 로그인은 최대 5일의 HttpOnly 서버 세션을 사용합니다. 일반 회원이 기본이며 교사·관리자 권한은 검증된 앱 전용 `reading_role`을 따릅니다. 로그아웃은 reading의 세션을 끝내고 공유 Firebase 프로젝트 전체의 토큰을 취소하지 않습니다. 상세 설정과 한계는 [로그인 안내](docs/18-auth-landing-demo.md)를 참고하세요.

## PDF·듣기

React PDF와 로컬 Nanum Gothic 글꼴로 실제 PDF 파일을 생성합니다. A4/A5, 긴 글의 자동 쪽 증가, 그림 응답, 책 전체 페이지를 지원합니다. PDF는 출력용이며 편집 데이터는 JSON으로 보관합니다. 브라우저 기록지 인쇄는 이름 있는 A4 규칙으로 분리했습니다. 학급 일괄 합본·중철 면배치·EPUB은 아직 없습니다.

고전 10편은 프로젝트를 위해 새로 쓴 한영 재서술본입니다. [작품과 출처](docs/11_classic_sample_sources.md)를 확인하세요. 장면별 한영 기기 낭독 100개와 승인받아 생성한 한국어 전권 AI 낭독 10개를 저장 파일로 재생합니다. 재생 시 생성 API를 호출하지 않습니다. 전권 음성과 장면의 자동 동기화는 없습니다. 가져온 원고·새 책은 설치된 `localService` 기기 음성이 있을 때 읽습니다. PDF에는 음성이 들어가지 않습니다. [낭독 기록](docs/13_ai_narration.md)

## 비용·연결 경계

기존 텍스트 AI 파일럿은 OpenAI GPT-6 Luna, 개발 검증 최대 10회·US$1, 2026-11-17 11:49 KST까지입니다. 양식 힌트도 같은 원장·한도를 따릅니다. 이번 문항 확장은 모의 응답으로 검증했고 실제 신규 호출은 없습니다. 이전 실제 텍스트 호출 2회와 TTS 10회는 각각 기존 승인 기록입니다. 자동 재시도·유료 모델 우회·자동 충전·새 구독은 없습니다. 프로덕션에서는 파일럿 API를 차단합니다.

책 삽화 API 준비 코드는 기본 비활성이며 실제 호출은 없습니다. **사용자 지시에 따라 이번 디자인 이미지는 구독 내장 imagegen만 사용하며 별도 이미지 API/프로젝트 API 키를 사용하지 않습니다.** 디자인용 16회 승인은 앱 런타임 삽화 API의 승인이 아닙니다. 그림체/요청문 선택만으로 이미지를 생성했다고 표시하지 않습니다.

운영 구조는 **GitHub `jejuailabs/reading` → 독립 Vercel + Firebase 인증**입니다. 승인된 업데이트 1회는 서버 오류로 이전 버전에 복구했으며, 준비된 수정본의 추가 배포는 별도 승인 후 실행합니다. Firebase 업무 데이터 저장·추가 AI 사용은 이 인증 구현으로 승인되거나 활성화되지 않습니다. `.env.local`, 서비스 계정, `.local` 비용 원장은 커밋하지 않습니다. **homework의 코드·DB·인증·키·배포는 수정하거나 연결하지 않습니다.**

미구현 운영 범위: 학교·학급 소속과 명부 관리, 학교 전체 관리자 기능, Firestore/Storage 업무 데이터 저장, 실시간 공동저작, 공개 공유·동의 관리, OCR, 링크 본문 자동 수집, 완성책 자동 생성, 모든 책의 자동 낭독극 변환, 불변 감사 로그. Google 인증·서버 세션·앱 역할 검사는 구현됐지만 실제 계정의 로그인 완료 검증은 남아 있습니다. PRD 목표와 구현 완료를 구별합니다.

## 검증

로그인·랜딩·체험 분리 구현은 **106개 테스트와 프로덕션 빌드**를 통과했습니다. 배포 장애 수정은 패키지 버전을 유지하면서 `firebase-admin`·`jwks-rsa`·`jose`를 Next 번들에 포함하는 방식입니다. 수정 후 빌드와 `require(esm)`을 끈 로컬 프로덕션 검사 **9개**를 통과했습니다. 검사는 생성한 시험용 키와 잘못된 토큰을 사용하며 실제 계정을 인증하지 않습니다. 로컬 Google 버튼의 실제 로그인 페이지 진입과 사용자 계정 로그인 완료는 구분합니다. 현재 공개 사이트는 복구한 이전 버전이며 실제 계정 인증·Firestore·학교 명부 연동 검증은 남아 있습니다.

```powershell
npm run typecheck
npm test
npm run build
```
