# 로컬 프로토타입 검증 — 2026-11-16

검증 범위는 로컬 Next.js 앱과 같은 브라우저 탭의 sessionStorage다. Firebase, Google 로그인, 생성형 AI, 원격 공동편집, homework 연동은 실행하지 않았다.

## 확인한 결과

- 도메인 모델 테스트 9개 통과: 원고와 완성본 분리, 여정 연결 변경 시 자료 보존, 질문 저장, 손상된 저장본 처리, 이전 저장 형식 호환.
- TypeScript 검사 통과. 프로덕션 빌드 통과.
- 로컬 홈 HTTP 200. 브라우저에서 수집한 오류 로그 0건.
- 독서 2장면 → 나의 질문 → 근거와 생각 작성 → 새로고침 후 보존 → 해당 질문을 책 만들기에 연결 → 제목·본문 수정 → 완성본 저장 → 독서 화면과 서재에 표시.
- 저장 모달의 Shift+Tab 초점 순환, Escape 닫기, 열었던 버튼으로 초점 복귀 확인.
- 교사 화면에서 질문 활동을 제외한 뒤에도 기존 질문과 원고 유지. 종이 참여는 선택한 활동에만 기록.
- 지도 구성안 선택 시 편지 구성안과 다른 초안 표시. 기존 작업은 프로젝트 선택에서 복원 가능.
- 영어로만 작성한 새 장면도 완성본 저장 버튼 활성화.
- 낭독극 표현 도움, 결석 배역 재배정, 성찰 기록과 운영 화면의 이벤트 표시 확인.
- 한국어/영어 및 밝은/어두운 테마 전환, 데스크톱/모바일 배치 확인. 모바일에서 닫힌 메뉴는 초점 탐색에서 제외되며 교사 메뉴 이동 시에도 닫힘.
- `.next/static`에서 관리자 개인키 표식·관리자 인증 변수 이름이 발견되지 않음. `.gitignore`의 환경 파일·서비스 계정 파일 제외 규칙 확인.

## 확인하지 않은 항목

실제 계정 인증·학교 권한 격리·서버 저장·Firebase Rules·클라우드 비용·다중 사용자 동시편집·전체 책 PDF 생성·실제 인쇄물·설치 음성의 청취 품질은 검증 범위에 포함되지 않는다. 운영 서비스 검증으로 해석하면 안 된다.

브라우저 검증용 서버는 확인 후 종료했다. `npm run dev`로 다시 실행할 수 있다.
