# 실제 공방 다운로드 PDF 시각 검증

검증일: 2026-11-16. 읽기 전용 검토이며 PDF 원본·앱 코드 변경, 외부 API·클라우드 호출은 없었다.

## 대상과 검증 범위

- 실제 브라우저 공방에서 WebP 파일을 업로드한 뒤 내려받은 PDF를 사용했다. 업로드·다운로드 동작은 root의 브라우저 검증이며, 이 검토는 그 결과 파일의 2쪽을 독립적으로 렌더링한 확인이다.
- 원본: `C:/Users/na/Downloads/검증용 창작책 · 함께 부른 구름-v17-A5.pdf`
- 원본 크기: 579,705 bytes.
- 원본 SHA-256: `E0ED687EBCF8F656DD12B7A188077E5685DF3605DE0D8589862FC79AA8F9B798`
- 문서: 표지 포함 5쪽, A5(419.53 × 595.28 pt), PDF 1.3, 비암호화.
- 확인한 쪽: 물리적 2쪽(첫 장면). 이번 검토가 나머지 4쪽 또는 모든 종류의 업로드 파일을 검증했다는 뜻은 아니다.

## 방법과 증거

1. Poppler `pdfinfo`로 페이지 수·용지 크기·문서 형식을 확인했다. 파일 바이트 크기는 Windows 파일 정보로 별도 확인했다.
2. Poppler `pdftoppm -f 2 -l 2 -r 144 -png`로 2쪽을 렌더링했다.
3. 렌더링 PNG를 직접 열어 그림, 한글 본문, 출처, 쪽 번호의 배치와 잘림 여부를 확인했다.
4. 설치된 PDF.js로 같은 쪽의 텍스트와 그래픽 연산을 검사했다. 래스터 이미지 출력 연산 1개, 한글 본문·출처·`2 / 5` 텍스트가 확인됐다. 텍스트 추출만으로 시각 검사를 대신하지 않았다.

## 결과: 확인한 2쪽 통과

- 업로드된 색연필 그림(세 아이가 종이를 함께 살펴보는 장면)이 본문 위에 정상 표시된다. 누락·깨진 이미지·찌그러짐·검은 배경이 없다.
- 본문 `작은 씨앗은 담장 아래에서 바람을 기다렸어요. “나는 어디로 가야 할까?”`가 한글 깨짐 없이 읽힌다. 줄바꿈은 페이지 폭 안에서 이루어진다.
- `그림 출처: 프로젝트 색연필 샘플 · 업로드와 PDF 검증용`이 본문 아래에 보존된다.
- 상단 `1장면 / 4장면`과 하단 `2 / 5`가 페이지 안에 표시된다.
- 그림·본문·출처·꼬리말이 서로 겹치거나 페이지 밖으로 잘린 부분은 관찰되지 않았다.
- 실제 종이 프린터 출력, 글과 그림의 교육적 적합성, 24장 대용량 사진책 출력은 이번 확인 범위가 아니다.

## 도구 경고

Poppler는 기본 표시 폰트 Symbol/ArialUnicode 미설치 경고를, PDF.js는 standardFontDataUrl 미설정 경고를 출력했다. 실제 렌더링에서 한글·기호·쪽 번호가 정상 표시됐고, 추출 결과도 일치했다. 따라서 이 파일의 검토한 2쪽에서 해당 경고로 인한 결함은 관찰되지 않았다.
