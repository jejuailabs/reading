# 고전 샘플·읽기·낭독·AI 로컬 검증

검증일: 2026-11-16. 작업 범위는 `reading` 로컬 프로토타입이다. Firebase 연결·운영 배포·실제 학생 데이터는 사용하지 않았다. `homework` 및 참고 프로젝트의 파일·데이터·서비스 설정을 변경하지 않았다.

## 콘텐츠와 화면

- 전래동화 5편: 흥부와 놀부, 해와 달이 된 오누이, 혹부리 영감, 토끼와 자라, 의좋은 형제.
- 이솝우화 5편: 토끼와 거북이, 사자와 생쥐, 여우와 포도, 북풍과 태양, 시골 쥐와 도시 쥐.
- 새로 쓴 어린이용 한국어·영어 재서술 50장면. 현대 출판본·번역의 복제가 아니며 출처/편집 범위는 [문서 11](../docs/11_classic_sample_sources.md)에 기록했다.
- 학생 질문 만들기·본문 확인·추론 활동 총 30개. 자기 질문을 먼저 쓰며 활동 예시는 접어서 표시한다.
- 기존 창작 샘플 3편을 유지했다. 서재 13권, 모음 필터의 전래 5권/이솝 5권, 검색과 직접 읽기·듣기 진입을 확인했다.
- 승인된 색연필 방향으로 두 모음 표지를 내장 이미지 생성 도구로 제작했다. 개별 장면 삽화로 표시하지 않는다. [원본과 프롬프트](illustration-concepts/classics-v1/prompts.json)를 보존했다.

## 음성 파일 검사

| 종류 | 파일 수 | 길이 합계 | 크기 합계 |
|---|---:|---:|---:|
| Windows Heami 한국어·Zira 영어 장면 음성 | 100 | 약 53분 45초 | 19,411,472바이트 |
| OpenAI tts-1-hd / nova 한국어 전권 AI 낭독 | 10 | 1,465.464초, 약 24분 25초 | 23,447,424바이트 |

장면 음성의 원고 해시·MP3 코덱·양수 길이를 확인했다. AI 음성 10편은 제목 포함 원고 해시, 파일 해시, ffprobe 길이, ffmpeg 전체 디코딩 검사를 통과했다. 캐시가 완성된 상태에서 생성기를 실행하면 `requests:0`, `cached:10`, `keysRead:false`로 끝났다. 재생은 저장 파일을 사용하며 음성 API를 호출하지 않는다.

모든 MP3를 청취해 발음·누락·추가 발화를 감수한 것은 아니다. 전권 AI 음성과 페이지 자동 동기화는 제공하지 않는다. 한국어는 AI 전권/기기 장면 음성을 선택하고 영어는 기기 장면 음성을 제공한다.

## 브라우저 확인

- 토끼와 거북이 장면 이동, 글자 24→26px, 질문의 책·장면 연결, 자기 질문 비공개 저장, 근거 장면 복귀.
- 한국어 장면 음성 재생과 2→3→4장면 연속 재생 후 마지막 장면에서 정지. 영어 재생과 1.25배속 확인.
- 흥부와 놀부 AI 전권 음성 `duration:180.624`, 재생 시간 증가, 1.25배속. 페이지를 넘겨도 전권 재생 유지.
- 전권→장면 전환 시 기존 음성 정지, 재생 요소 1개 유지. 영어 전환 시 해당 영어 장면 파일 선택·재생.
- 라이트/다크 및 한영 본문 표시. 모바일 390×844 검증에서 문서 가로 넘침 없음(`scrollWidth=clientWidth=344`).
- 고전 전권 A5 인쇄용 본문·질문 기록지 구현. 실제 프린터 출력·제본 면배치 검증은 하지 않았다.

## 실제 텍스트 AI 확인

로컬 동일 출처 검사에서 Next의 내부 `localhost` 정규화와 브라우저 `127.0.0.1`의 차이를 수정했다. 내부 URL은 loopback으로 제한하며 브라우저 Host/Origin의 정확한 일치, 로컬 전달 주소 검사와 서버 쿠키는 유지했다. 차단된 초기 handshake는 공급자 호출 전에 끝났다.

실제 유료 요청은 아래 2회이며 모두 완료됐다.

| 용도 | 입력 토큰 | 출력 토큰 | 추정 US$ |
|---|---:|---:|---:|
| 학생 질문 코칭 | 1,142 | 366 | 0.0002972 |
| 교사 구성안 3개 | 695 | 1,101 | 0.0006200 |
| 합계 | 1,837 | 1,467 | 0.0009172 |

학생의 “토끼는 앞서고 있었는데 왜 멈춰도 괜찮다고 생각했을까?”를 유지하고 본문 인용·확인/추론 탐색 질문을 별도 표시했다. 학생 답란을 대신 채우지 않았다.

교사 입력 `제주 애월 / 3–4학년 / 서로 다른 마음을 이해하기 / 모험 동화`에 서로 다른 구성안 3개가 반환됐다. 첫 구성안 “바람을 따라간 종이배”를 선택하자 편집 가능한 3장면 초안으로 옮겨졌고, 이전 프로젝트 “바람이 남긴 다음 편지”도 프로젝트 선택 목록에 유지됐다. 생성 결과는 애월을 창작 배경으로 구분했으며 자동 출판하지 않았다. 구성안은 완성 동화 본문이 아니고 삽화는 준비된 정적 자산을 선택한다.

## 비용과 실행 경계

- 텍스트: 승인 10회·US$1 중 2회 사용. 추정 US$0.0009172, 보수적 원장 예약 합계 US$0.005067. 로컬 개발 파일럿은 2026-11-17 11:49 KST 만료.
- AI 낭독: 승인 10회·US$1 중 10회 사용. 10,359자, 추정 US$0.31077. 예산 잔액이 있어도 호출 수를 모두 사용했으므로 추가 생성은 새 승인 필요.
- 두 종류 합계 12회, 추정 **US$0.3116872**. 제공자 청구 실액·세금·환율을 조회한 값은 아니다.
- 자동 재시도·유료 대체 모델·정기 결제·자동 충전·클라우드 배포 없음. 운영 저장·전송·AI 사용 비용은 별도 범위다.
- 학교 인증·Google 로그인·Firestore/Storage·실시간 공동저작은 아직 미연결이다. 미리보기 역할 선택은 실제 권한 검사가 아니다.

## 검사 결과

- `npm test`: 37개 통과. 모델 상태 보존, 원고/음성 대응, AI 구조 검증, 운영·원격·기간 차단, 쿠키, 동시 예약, 10회/US$1 한도, 실패 비용 보존을 검사했다. 단위 테스트의 공급자 transport는 가짜이며 추가 API 비용이 없다.
- `npm run build`: TypeScript 포함 성공. Next.js 16.4.6, Node.js 22.21.0.
- 빌드된 앱의 로컬 실행: 서재 HTTP 200, AI MP3 HTTP 200 및 `audio/mpeg`. 프로덕션 AI 초기화 요청은 HTTP 503 / `AI_APPROVAL_REQUIRED`로 차단됐으며 텍스트 사용 원장 해시는 변경되지 않았다. 검증 후 프로덕션 서버도 종료했다.
- TypeScript 단독 검사도 통과했다. 기존 Node의 MODULE_TYPELESS_PACKAGE_JSON 경고는 테스트 실패가 아니다.
- 개발 검증 서버는 종료했다. 실행은 프로젝트 루트에서 `npm run dev`, 주소는 `http://127.0.0.1:3100`이다.
